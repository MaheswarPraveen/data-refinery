    How this run worked

    A coordinator on Cloudflare hands math problems to volunteer nodes on free Kaggle and Colab GPUs. For every problem, each node picks a random Llama model (1B, 3B or 8B) and a random instruction style, solves it, and signs the answer. The coordinator collects 3 independent answers, keeps the problem if they agree, and asks a 70B Llama judge when only two agree. Honeypots, timing checks and quarantine stop nodes from faking work. The kept problems, each with a full record of who answered what, become training data for a larger model. If small models agreeing can teach a bigger one, that's weak-to-strong generalisation (Burns et al., 2023).
